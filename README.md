# RouteSpec

以**路由 wiki**与**契约文档**为核心的 AI 编码工作流技能套件，面向个人开发者与团队。路由 wiki 回答"任意角度提到某个词汇——业务场景、架构场景或代码场景——应先读哪些代码与契约"，跨会话持续维护；技能工作流服务于它的构建与养护，而非反过来。安装后各技能由 agent 按 `description` 自动匹配触发。

## 设计动机

大型工程中，AI 定位代码常依赖全仓搜索或连读多份文档，token 代价高且随工程规模恶化；路由文档缺少硬约束时会随任务沉积实现描述而膨胀、随代码演进而过时。RouteSpec 以三个手段应对：

- **指针网络**：路由页只记"某词汇 → 先读哪些代码与契约"；实现细节以代码为准、约束以契约文档为准，页面不复制两者内容，从结构上阻断冗余沉积。
- **任意角度命中**：业务场景、架构场景、代码标识符都经 index 一次读取命中页面；命中不了的词汇记 miss 并回填别名，命中率随使用持续上升。
- **可机械判定的自检**：lint 九项（防过时 3 项、防冗余 6 项）让膨胀与漂移在每次同步时被检出并就地修复，不依赖人工清理。

## 安装与更新

通过 [skills CLI](https://vercel-labs-skills.mintlify.app) 安装：

```bash
npx skills add https://github.com/GmwEnterprise/route-spec
```

升级：

```bash
npx skills update    # 更新全部已安装技能
npx skills update -g # 更新全局安装的技能
```

升级后，既有的 `docs/routespec/feature-routes/` 目录或 `docs/routespec/feature-routes.md` 单文件仍会被读取（覆盖状态标 `partial`），并在下一次 route-sync 时按迁移指南分批收敛到路由 wiki。

## 技能

| 技能 | 作用 |
|---|---|
| `route-lookup` | 查询路由 wiki，以任意角度词汇定位核心代码与契约文档，并判定覆盖状态与下一步。 |
| `route-sync` | 养护路由 wiki 与契约文档：首次创建、日常同步、自检（lint）、遗留结构迁移。 |
| `route-debug` | 借助路由 wiki 查询结果做系统化根因定位的调试工作流（先定位根因，再移交修复）。 |
| `spec` | 中大型/范围不清任务的方向确认与可执行拆解（单一可选产物 `spec.md`）。 |
| `exec-plan` | 执行变更，以"验证门（跑命令读新鲜输出）"为唯一硬性完成依据。 |

## 审查子代理

| 子代理 | 作用 |
|---|---|
| `code-reviewer` | 对已通过主代理验证门的改动做只读静态风险与测试有效性审查；配置位于 `agents/code-reviewer.md`。 |

审查按行为变更、跨模块、鉴权与数据敏感等风险触发；主代理负责需求与改动上下文、修复及复验，审查子代理不修改文件。任务目录存在时，评审报告与方案、执行产物归档在同一目录。

## 工作流

- 小而明确的修改 → `route-lookup` → `exec-plan`
- bug / 测试失败 / 异常行为 → `route-lookup` → `route-debug` →（局部修复 `exec-plan`；范围不清或广则 `spec` → `exec-plan`）
- 中大型或范围不清 → `route-lookup` → `spec` → `exec-plan`
- 功能变更完成后 → `route-sync`

路由 wiki 不存在时，`route-lookup` 会建议用 `route-sync` 的"首次创建"模式建立。提交由开发者惯用的提交流程完成，提交信息记录任务目录位置。

## 路由 wiki 与契约文档

- 路由 wiki 位于 `docs/routespec/wiki/`：`index.md` 是唯一查询入口（每页一行，业务功能与技术机制两组分节）；路由页 ≤ 12 行，只含别名、说明、核心（1-3 个起步阅读点）、契约、相关链接；`log.md` 记 miss / sync / lint 三类单行日志。
- 页面承接任意角度词汇：功能页对应业务场景，机制页对应架构与技术场景；实现细节以代码为准，页面不复制代码与契约内容。
- 契约文档位于 `docs/integration/`：收录代码不可推导、必须显式遵守的约束——跨端协议、接口兼容承诺、数据契约、架构边界、隐式约定、术语定义；条款式写作，同一契约唯一权威文档。
